## 🚀 Featured Project

### 🌧️ Arduino Rain Detection System

<p align="center">
  <img src="https://img.shields.io/badge/Arduino-00979D?style=for-the-badge&logo=arduino&logoColor=white"/>
  <img src="https://img.shields.io/badge/C%2FC%2B%2B-00599C?style=for-the-badge&logo=cplusplus&logoColor=white"/>
  <img src="https://img.shields.io/badge/Embedded-Systems-2563EB?style=for-the-badge"/>
</p>

An Arduino-based rain detection system that detects rainfall using a rain sensor and automatically activates an LED and buzzer.

### 🔩 Components

- Arduino Uno
- Rain Sensor Module
- Buzzer
- LED
- 220Ω Resistor
- Breadboard
- Jumper Wires

### ✨ Features

- 🌧️ Detects rainfall using a rain sensor
- 🔔 Automatically activates the buzzer
- 💡 Turns ON the LED when rain is detected
- ⏱️ Automatically turns OFF the alarm after 10 seconds
- 🔄 Resets when the sensor becomes dry
- 📟 Displays sensor readings through Serial Monitor
