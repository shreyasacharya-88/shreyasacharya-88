## 🚀 Featured Project

### 🌧️ Arduino Rain Detection System

<p align="center">

<img src="https://img.shields.io/badge/Arduino-FFFFFF?style=for-the-badge&logo=arduino&logoColor=00979D"/>

<img src="https://img.shields.io/badge/C%2FC%2B%2B-FFFFFF?style=for-the-badge&logo=cplusplus&logoColor=00599C"/>

<img src="https://img.shields.io/badge/Embedded%20Systems-FFFFFF?style=for-the-badge&logoColor=2563EB"/>

</p>

<p align="center">

<img src="https://readme-typing-svg.demolab.com?font=Fira+Code&size=18&duration=3000&pause=1000&color=2563EB&center=true&vCenter=true&width=750&lines=Smart+Rain+Detection+%7C+Arduino+%7C+Sensors;Detect+Rain+%7C+Activate+Alarm+%7C+Automatic+Reset" />

</p>

> An Arduino-based rain detection system that detects rainfall using a rain sensor and automatically activates an LED and buzzer.

### 🔩 Components

- 🔌 Arduino Uno
- 🌧️ Rain Sensor Module
- 🔔 Buzzer
- 💡 LED
- 🟦 220Ω Resistor
- 🔲 Breadboard
- 🔗 Jumper Wires

### ✨ Features

- 🌧️ Detects rainfall using a rain sensor
- 🔔 Automatically activates the buzzer
- 💡 Turns ON the LED when rain is detected
- ⏱️ Automatically turns OFF the alarm after 10 seconds
- 🔄 Resets when the sensor becomes dry
- 📟 Displays sensor readings through Serial Monitor
