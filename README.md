## 🚀 Featured Project

### 🌧️ Arduino Rain Detection System

An Arduino-based smart rain detection system that detects rainfall using a rain sensor and automatically activates an LED and buzzer.

**🔩 Components**

- Arduino Uno
- Rain Sensor Module
- Buzzer
- LED
- 220Ω Resistor
- Breadboard
- Jumper Wires

**✨ Features**

- 🌧️ Detects rainfall using a rain sensor
- 🔔 Automatically activates the buzzer
- 💡 Turns ON the LED when rain is detected
- ⏱️ Automatically turns OFF the alarm after 10 seconds
- 🔄 Resets automatically when the sensor becomes dry
- 📟 Displays sensor readings through Serial Monitor

**💻 Technologies**

`Arduino` `C/C++` `Embedded Systems`
